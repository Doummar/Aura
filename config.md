# Aura: The Pure HUD v1.0.0

- Session Summary now shows only when review ends with 0 cards left.
- Session Summary uses a clean card-style popup for readability.
- Best focus streak tracking is fixed to reflect focused study time.
- Break popup now opens centered on the Anki window.
- Best focus streak now shows comparison vs average with colored arrow trend.
- Break popup buttons are repositioned for clearer action flow.
- Added Drawing Panel-style addon header and metadata constants in `__init__.py`.
- During Break/Long Break, toolbar color now stays unchanged; only break label text is green.
- HUD now auto-detects Anki dark/light theme and switches text/separator/progress contrast accordingly.
- Added Aura HUD, Pomodoro only, and Custom modes.
- Added display toggles for focus score, cards left, and progress bar.
- Session Summary now includes total break time.
- Settings and Help Guide are scrollable on smaller screens.
- Focus-score wording is clearer: Aura now describes it as focus rhythm, not a grade.
- Added optional cross-deck Pomodoro mode so the timer can continue across small decks.
